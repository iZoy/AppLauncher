# Changelog

## 1.0.0

### Added

- First public Windows release.
- Migrated the project and self-contained release builds to .NET 10 LTS.
- Local application discovery with incremental scanning and noise filtering.
- Search by display name or executable name, with Enter launch support.
- Pinned and regular application sections with persistent ordering.
- Context-menu actions for launch, administrator launch, folder access, rename, hide, and pin/unpin.
- Tray controls for showing the launcher, language selection, taskbar pinning, and exit.
- Windows 11 Acrylic background with a Windows 10-compatible fallback.
- Local configuration, application cache, icon cache, and diagnostic logs.

### Fixed

- Bound diagnostic and crash logs to prevent old or repeated errors from consuming excessive disk space.
